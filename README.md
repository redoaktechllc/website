# Red Oak — company website

The official marketing site for **Red Oak LLC**, a web-design studio for local businesses in Northeast Ohio.

Bespoke, zero-dependency static site (HTML + CSS + vanilla JS). No framework, no build step. Hosted on Vercel; custom domain `redoakllc.tech`.

## Develop

```bash
node scripts/serve.mjs      # http://localhost:4321
```

## Deploy

Push to `main` → Vercel auto-deploys.
